# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Vidora,
please **do not** open a public issue. Instead, report it privately.

- **Email:** saimrazaytt@gmail.com
- **GitHub:** use the [private security advisories](https://github.com/SaimRaza885/Vidora/security/advisories/new) feature on the repository.

Please include as much of the following as possible:

- A description of the vulnerability and its impact.
- Steps to reproduce it.
- Affected versions.
- Any suggested mitigation.

You should receive a response within a reasonable timeframe. We appreciate your
help in keeping Vidora and its users safe.
